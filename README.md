## 📑 Portfolio Structure & Features

The HTML structure includes the following semantic sections:

- **Header & Navigation:** Includes student name, course details, and jump links for seamless page navigation.
- **Profile:** Basic personal details and profile picture placeholder.
- **About Me:** Introduction, career goals, and core technical interests in AI/ML & Frontend Development.
- **Hobbies:** Key interest areas presented in a clean list format.
- **Education:** Semantic `<table>` detailing qualifications, university/board, completion years, and current status.
- **Marksheets:** Placeholders for Class 10 and Class 12 academic marksheets.
- **Certificates:** Placeholders for technical course certificates and workshops.
- **Contact Section:** Personal contact details alongside a functional HTML contact form (`<form>`).
- **Footer:** Copyright information and assignment details.

## 🚀 Getting Started

### 1. Clone the Repository
```bash
git clone https://github.com/krishabh7928-jpg/updated_portfolio.git
cd updated_portfolio
```

### 2. View in Browser
- **Option 1:** Double-click `index.html` to open it directly in any modern web browser.
- **Option 2:** Launch a local HTTP server using Python:
  ```bash
  python -m http.server 8000
  ```
  Then navigate to `http://localhost:8000/` in your browser.
